# AxaFrance.WebEngine

Core of the AXA WebEngine Test Automation Framework: base data structures, test lifecycle (`TestCase`, `SharedAction`), parameter/test-data model and configuration for Web and Mobile test automation on .NET.

```powershell
dotnet add package AxaFrance.WebEngine
```

Use with `AxaFrance.WebEngine.Web` (Selenium) or `AxaFrance.WebEngine.MobileApp` (Appium) to drive browsers and devices, and `AxaFrance.WebEngine.Runner` to execute Keyword-Driven suites.
