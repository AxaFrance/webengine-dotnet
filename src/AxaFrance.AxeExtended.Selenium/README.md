# AxaFrance.AxeExtended.Selenium

Accessibility testing for Selenium with the axe-core engine, integrated with the AXA WebEngine Framework: run axe analyses from your WebDriver sessions and feed the results into the HTML report pipeline.

```powershell
dotnet add package AxaFrance.AxeExtended.Selenium
```
