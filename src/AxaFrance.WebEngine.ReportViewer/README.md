# AxaFrance.WebEngine.ReportViewer

ReportViewer executable that opens and explores AXA WebEngine test reports (overall dashboard and per-page details, including accessibility results).

Launch `ReportViewer.exe` and open a generated report folder. See `report-viewer.md` in the documentation for details.
