# AxaFrance.WebEngine.Runner

WebRunner executable that runs Keyword-Driven automated tests built with the AXA WebEngine Framework (`TestCaseWeb` / `TestCaseApp` suites with XML test data).

```powershell
WebRunner.exe --testSuite "MySuite.xml" --testData "Data.xml"
```

See `webrunner.md` in the documentation for all command-line options.
